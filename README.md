# Subalakshmi K – Portfolio

Personal portfolio website (single static page, no build step).

## Host on GitHub Pages
1. Create a public repo named `Subha-k07.github.io` on GitHub.
2. Push these files to the `main` branch.
3. In the repo: Settings > Pages > Deploy from a branch > `main` / root.
4. Your site goes live at https://subha-k07.github.io (takes 1–2 minutes).

## Edit
All content, styles and links live in `index.html`.
